# 简体中文

**镇江公交经典翻牌票价表生成工具**

一款面向公交爱好者及公交运营相关人员的经典镇江公交（ZJGJ）风格翻牌票价表生成工具。只需输入线路名称、上下行起讫站及票价数据，即可快速生成具有经典风格的翻牌票价表，并导出为 SVG 或 PNG 格式。

## 项目简介

翻牌式票价表是镇江公交具有代表性的信息展示形式之一。

本项目旨在重现经典镇江公交（ZJGJ）翻牌票价表的视觉风格，让公交爱好者及有相关需求的用户能够自行制作翻牌票价表，用于收藏、展示、研究及其他正当用途。

无需掌握专业绘图软件，只需填写相关数据，即可生成属于自己的翻牌票价表。

## 功能特性

- **经典 ZJGJ 风格**：重现经典镇江公交翻牌票价表的视觉设计。
- **自定义线路信息**：输入公交线路名称。
- **自定义行驶方向**：分别设置上行及下行的起点站与终点站。
- **自定义票价数据**：根据需求输入票价信息。
- **自动生成**：根据输入数据自动生成翻牌票价表。
- **多格式导出**：支持保存为 SVG 或 PNG 格式。
- **跨平台使用**：通过现代网页浏览器即可使用，支持桌面端和移动端。

## 技术与设计

- **开发辅助工具**：DeepSeek Harness
- **UI 设计参考**：[Smartisan UI Skill](https://github.com/lemonteaau/smartisan-ui-skill)

本项目在 UI 设计过程中使用了 Smartisan UI Skill，并将其设计规范作为界面设计参考。

本工具使用的线路名称、起讫站名称及票价数据均由用户自行输入。

本项目不提供官方公交线路及票价数据，也不对用户输入数据的准确性作出保证。

# English

**Classic Zhenjiang Public Transport Flipping Fare Schedule Generator**

A web-based tool designed for bus enthusiasts and public transit professionals to generate classic ZJGJ-style flipping fare schedules. Simply enter the route name, terminal stations for both directions, and fare information to create a traditional-style fare schedule, exportable as SVG or PNG.

## Introduction

Flipping fare schedules are a distinctive form of passenger information display found on Zhenjiang Public Transport.

This project aims to recreate the visual style of classic Zhenjiang Public Transport (ZJGJ) flipping fare schedules, allowing bus enthusiasts and other interested users to create their own schedules for collection, display, research, and other legitimate purposes.

No professional graphic design software is required. Simply enter the relevant information and generate your own flipping fare schedule.

## Features

- **Classic ZJGJ Style**: Recreates the visual design of classic Zhenjiang Public Transport flipping fare schedules.
- **Custom Route Information**: Enter your own bus route name.
- **Bidirectional Route Configuration**: Specify the starting and terminal stations for both directions.
- **Custom Fare Information**: Enter fare data according to your requirements.
- **Automatic Generation**: Automatically generates a flipping fare schedule based on the supplied information.
- **Multiple Export Formats**: Save generated schedules as SVG or PNG files.
- **Cross-Platform Compatibility**: Works with modern web browsers on both desktop and mobile devices.
